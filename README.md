## 🙋 About me

I'm a FullStack Developer focused on Web3 — I build decentralized apps end-to-end, from the smart contract to the interface, always designed for people who've never used a crypto wallet before.

My edge is turning complex blockchain tech into products that are simple, secure, and easy to use. I've applied this to decentralized social platforms, private communication tools, and on-chain portfolios — always with privacy-first architecture.

- 🔗 Core stack: **React, Next.js, TypeScript** and **Solidity / Ethers.js**
- 🤖 AI (LLM) integration experience when a project calls for it
- 🌍 Freelancing since 2023 · Fully remote · Available across international time zones
- 🔐 Privacy-first architecture, always
